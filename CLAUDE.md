# Project Rules

## Start here

Read [AGENTS.md](AGENTS.md) and [docs/llm-onboarding.md](docs/llm-onboarding.md)
before making changes. They define the shared repository workflow, Gutenberg
editing requirements, related-file checklist, and verification expectations.

## Git
- NEVER add Co-Authored-By to commit messages or PR descriptions
- Use conventional commits (feat:, fix:, docs:, refactor:, test:, chore:)

## Iterators AI Skills
- Specs go to `docs/specs/`, plans go to `docs/plans/`
- Task context is stored in `.iterators/current-task.json`
- Project config is in `.iterators/config.yml`
